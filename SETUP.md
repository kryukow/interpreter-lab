# Interpreter Lab — первая версия

Самостоятельное iOS-приложение с дизайном Interpreter Live: черно-белый интерфейс, две кнопки удержания, 40 столбиков звука, символ бесконечности и настройки. Старый Realtime/PCM-движок здесь не используется.

## Схема
1. Удерживаешь «Русский» или «Deutsch», дожидаешься вибрации и говоришь.
2. Отпускаешь кнопку — Apple Speech завершает распознавание.
3. OpenAI Responses API получает **текст**, а не аудиозапись, и возвращает готовый перевод.
4. AVSpeechSynthesizer от Apple произносит готовую фразу. Голоса RU/DE выбираются в настройках.
5. Прослушать повторно можно бесплатно, без запроса к OpenAI; распознанный текст разрешено исправить вручную.

## Сборка
- Xcode + XcodeGen, iOS 18.4+; отдельный Bundle ID: `org.interpreter.lab`.
- Установить XcodeGen: `brew install xcodegen`; затем выполнить `swift scripts/make-icon.swift` и `xcodegen generate` в корне репозитория. Скрипт подготавливает отдельную иконку LAB в формате 1024×1024 RGB.
- Открыть `InterpreterLab.xcodeproj`, схема `InterpreterLab`.
- GitHub Actions → **Interpreter Lab iOS** собирает симулятор и iPhone, публикует **Interpreter-Lab-0.2.1-Unsigned-iPhone**. Для установки IPA на реальное устройство его необходимо подписать.

## Доступ
- **По умолчанию** открой настройки → «ChatGPT» → «Войти через ChatGPT». Авторизация использует проверенный код из основной программы Interpreter (OAuth/PKCE, проверка ID-token, обновление сессии, список доступных моделей); для Lab хранилище отдельное. Затем выбери модель из списка и говори.
- Платный API выбирается вручную в разделе «Способ перевода» как альтернативный эксперимент.
- Для **дополнительного API-режима** нужен персональный платный ключ. Он сохраняется отдельно в Keychain и не включён в исходники.
- В версии 0.2.1 используется Sign in with ChatGPT для текстового перевода в рамках доступных лимитов плана. Вход не заменяет Apple Speech и Apple TTS. Этот путь необходимо испытать на физическом iPhone.
- Базовая модель перевода — `gpt-4.1-mini`; опция `gpt-4.1`.
- Системное озвучивание Apple бесплатно. Платное OpenAI TTS и клонирование голоса оставлены для последующих сравнений.

## Ограничения
- Если распознавание выбранного языка не поддерживается локально, Apple Speech может обрабатывать аудио через серверы Apple. Передача аудио в OpenAI отсутствует.
- Контекст текста отправляется в OpenAI с `store:false`.
- После отпускания кнопки ожидаются финальное распознавание и текстовый ответ, то есть задержка выше, чем при streaming audio.
- При длинных паузах Apple Speech может завершить фразу раньше отпускания кнопки: это требует проверки непосредственно на iPhone.
- Отдельное приложение устанавливается рядом с Interpreter Live и не изменяет его код или данные.

## Изменения 0.2.1
- Исправлен HTTP 400 после авторизации ChatGPT: запросы подписки теперь используют обязательный потоковый формат Responses API и ждут события `response.completed` перед озвучиванием.
- В случае ошибки показывается конкретное сообщение OpenAI и идентификатор запроса (если он предоставлен).
- Перевод по-прежнему поступает в Apple TTS как одна готовая строка: промежуточные аудиофрагменты не воспроизводятся.
