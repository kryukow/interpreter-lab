# Interpreter Lab — первая версия

Самостоятельное iOS-приложение с дизайном Interpreter Live: черно-белый интерфейс, две кнопки удержания, 40 столбиков звука, символ бесконечности и настройки. Старый Realtime/PCM-движок здесь не используется.

## Схема
1. Удерживаешь «Русский» или «Deutsch», дожидаешься вибрации и говоришь.
2. Отпускаешь кнопку — Apple Speech завершает распознавание.
3. OpenAI Responses API получает **текст**, а не аудиозапись, и возвращает готовый перевод.
4. AVSpeechSynthesizer от Apple произносит готовую фразу. Голоса RU/DE выбираются в настройках.
5. Прослушать повторно можно бесплатно, без запроса к OpenAI; распознанный текст разрешено исправить вручную.

## Сборка
- Xcode + XcodeGen, iOS 18.4+; отдельный Bundle ID: `org.interpreter.lab`.
- Установить XcodeGen: `brew install xcodegen`, затем `xcodegen generate` в корне репозитория.
- Открыть `InterpreterLab.xcodeproj`, схема `InterpreterLab`.
- GitHub Actions → **Interpreter Lab iOS** собирает симулятор и iPhone, публикует **Interpreter-Lab-0.1.0-Unsigned-iPhone**. Для установки IPA на реальное устройство его необходимо подписать.

## Доступ
- Для первой версии нужен персональный **платный OpenAI API-ключ**, его можно добавить в настройках. Он сохраняется отдельно в Keychain и не включён в исходники.
- Подписка ChatGPT Plus в версии 0.1.0 не используется.
- Базовая модель перевода — `gpt-4.1-mini`; опция `gpt-4.1`.
- Системное озвучивание Apple бесплатно. Платное OpenAI TTS и клонирование голоса оставлены для последующих сравнений.

## Ограничения
- Если распознавание выбранного языка не поддерживается локально, Apple Speech может обрабатывать аудио через серверы Apple. Передача аудио в OpenAI отсутствует.
- Контекст текста отправляется в OpenAI с `store:false`.
- После отпускания кнопки ожидаются финальное распознавание и текстовый ответ, то есть задержка выше, чем при streaming audio.
- При длинных паузах Apple Speech может завершить фразу раньше отпускания кнопки: это требует проверки непосредственно на iPhone.
- Отдельное приложение устанавливается рядом с Interpreter Live и не изменяет его код или данные.
